Configure Bitcoin Core to use Onion nodes in addition to IPv4 and IPv6 nodes?

Question

How do I configure Bitcoin Core to use Onion nodes in addition to IPv4 and IPv6 nodes?

Currently, I have onion=127.0.0.1:9050 in bitcoin.conf, but the peers tab shows I have no Tor peers (just IPv4 and IPv6 ones).

Answer 1

With onion=... you only tell bitcoind how to make outbound connections to the Tor network. In order to be reachable yourself on the Tor network, you need to have what is called a "hidden service", which is the equivalent of an IP address on the Tor network. Tor is rather unusual in that you do not need such an address to make outbound connections; it is only needed to receive inbound connections.

For the details of how to create a hidden service, see the Bitcoin Core Tor documentation, but there are roughly two ways:

  • Give bitcoind permission to ask tor to create a hidden service on its behalf (by opening the control port).
  • Configure tor yourself to create a hidden service for you and to forward it to bitcoind, which you then need to tell what that hidden service address is (so it can advertise to other peers).
