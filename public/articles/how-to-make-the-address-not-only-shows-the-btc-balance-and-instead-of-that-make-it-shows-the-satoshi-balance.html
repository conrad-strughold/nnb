Question

How to make the address not only shows the BTC balance, and, instead of that, make it shows the satoshi balance?

Im working with this script:

<?php
if($_POST["address"]){
    $address=$_POST["addressTXT"];
    function getBalance($address) {
        return file_get_contents('https://blockchain.info/q/addressbalance/'. $address);
    }
    echo getBalance($address).' BTC';
}else{
    echo <<<EOF
    <form action="index.php"method="POST">
        <input type="text" name="addressTXT"size="100">
        <input type="submit" name="address">
    </form>
EOF;
}
?>

It supossed to show the entire balance, including satoshis, but not. Any solution? Thanks anyway!

Answer 1

As we all know, 1 Bitcoin is 100000000 Satoshi.

So, for example, 1234567890123 Satoshi is 1234.567890123 Bitcoin.

When I point an ordinary web browser at https://blockchain.info/q/addressbalance/1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa it replies

10297591076

When I do the same at https://blockchair.com/bitcoin/address/1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa its reply includes

Main balance + 102.97591076 BTC

So the response you are seeing is in integer units of Satoshi.

Just do a floating point division of Blockchain's answer by 108 to get a decimal answer if that is what you seek.
